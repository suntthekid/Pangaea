# 🏨 Hotel Alert — โรงแรมราคาถูก พระราม 9 · ห้วยขวาง · รัชโยธิน

ระบบแจ้งเตือนเมื่อมีที่พักราคาถูก **อยู่ในแนวถนน** ที่สนใจ ได้แก่ พระราม 9, รัชดา–ห้วยขวาง และรัชโยธิน
แจ้งผ่าน **LINE / Telegram / Discord** หรือแสดงบนหน้าจอ ใช้แค่ Python 3.10+ ไม่ต้องติดตั้งไลบรารีเพิ่ม

## ทำงานอย่างไร

1. **รับข้อมูล:** อ่านผลค้นหาโรงแรมจากไฟล์ JSON หรือ URL (ใส่ได้หลายแหล่ง ถ้าโรงแรมซ้ำกันจะเก็บราคาที่ถูกที่สุด)
   - รับผลดิบจาก Booking.com (`{"accommodations": [...]}`) ได้โดยตรง
   - หรือรูปแบบย่อ: `{"checkin", "checkout", "hotels": [{"id","name","price","lat","lng","review_score","reviews","type","url"}]}` (ดู `sample_snapshot.json`)
2. **กรองตามแนวถนน:** แต่ละย่านคือเส้นที่ลากผ่านพิกัดหลายจุด (`route`) ที่พักต้องอยู่ห่างจากเส้นไม่เกิน `buffer_km`
   | ย่าน | แนวเส้นทาง |
   |---|---|
   | พระราม 9 | MRT พระราม 9 → Central พระราม 9 → พระราม 9 ช่วงตะวันออก |
   | ห้วยขวาง–รัชดา | MRT พระราม 9 → ศูนย์วัฒนธรรมฯ → ห้วยขวาง → สุทธิสาร → รัชดาภิเษก → ลาดพร้าว |
   | รัชโยธิน | ลาดพร้าว → แยกรัชโยธิน → BTS รัชโยธิน → เสนานิคม |
3. **กรองตามเงื่อนไข:** ราคาต่อคืนไม่เกินเพดาน (ตั้งแยกรายย่านได้), คะแนนรีวิวขั้นต่ำ, ตัดประเภทที่ไม่ต้องการ (เช่น แคปซูล),
   ช่วงวันเช็คอิน `checkin_from`/`checkin_to`, วันในสัปดาห์ `checkin_weekdays` (0=จ. … 6=อา.) และแหล่งข้อมูล `sources`
   ข้อความแจ้งเตือนมีลิงก์เทียบราคาบน Trip.com ตามวันที่เข้าพักให้ด้วย
4. **ไม่แจ้งซ้ำ:** จำราคาที่เคยแจ้งไว้ใน `state.json` จะแจ้งอีกครั้งเฉพาะเมื่อ **ราคาลดลง ≥ `price_drop_pct`%**
5. **ส่งแจ้งเตือน** และสร้างรายงาน HTML (ถ้าสั่ง)

## เริ่มใช้งาน

```bash
cd hotel-alert
cp config.example.json config.json         # ปรับเพดานราคา/ย่าน/ช่องทางแจ้งเตือนได้ที่นี่
python3 hotel_alert.py sample_snapshot.json --dry-run --html report.html
```

ตัวเลือกที่ใช้บ่อย

| ตัวเลือก | ความหมาย |
|---|---|
| `--dry-run` | แสดงบนหน้าจออย่างเดียว ไม่ส่ง ไม่บันทึก state |
| `--channels console,line` | เลือกช่องทาง (แทนค่าใน config) |
| `--html report.html` | สร้างหน้ารายงานรวมทุกแห่งที่ผ่านเงื่อนไข |
| `--all` | แจ้งทุกแห่งแม้เคยแจ้งแล้ว |
| `--state path` | ตำแหน่งไฟล์จำราคา |

## หน้าเว็บตรวจสอบและกรอง

### วิธีที่ง่ายที่สุด: ดับเบิลคลิก `hotel-alert.html`

ไฟล์เดียวที่รวมหน้าเว็บ ย่าน และข้อมูลไว้แล้ว เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งหรือรันอะไร
เมื่อมีข้อมูลใหม่ อัปโหลดไฟล์ JSON ในหน้าเว็บได้ทันที หรือสร้างไฟล์ใหม่ที่ฝังข้อมูลล่าสุดไว้ในตัว:

```bash
python3 build_web.py snapshot.json      # ได้ hotel-alert.html ที่มีข้อมูลชุดใหม่
```

### แบบเว็บเซิร์ฟเวอร์ (สำหรับพัฒนาต่อ)

```bash
cd hotel-alert
python3 -m http.server 8000
```
จากนั้นเปิด <http://localhost:8000/web/>

- โหลดข้อมูลได้ 4 ทาง: ข้อมูลตัวอย่าง, อัปโหลดไฟล์ JSON (เลือกหลายไฟล์ได้), วาง JSON, หรือใส่ URL พร้อมตั้งให้ดึงซ้ำอัตโนมัติ
- ตัวกรองวันที่เข้าพัก: ช่วงวันเช็คอิน (ตั้งแต่–ถึง), เลือกเฉพาะวันที่มีข้อมูล, วันในสัปดาห์ (เช่น เฉพาะ ส.–อา.) และรวมโรงแรมเดียวกันให้เหลือวันที่ถูกที่สุด
- กราฟเทียบราคาถูกสุดของแต่ละวันที่เข้าพัก กดแท่งเพื่อเลือกวันนั้น
- **Trip.com:** ปุ่มเปิดหน้าค้นหา Trip.com ตามย่าน/วันที่/จำนวนผู้ใหญ่ และทุกรายการมีลิงก์ "เทียบบน Trip.com" ตามวันที่ของรายการนั้น
  (Trip.com ไม่มี API สาธารณะ ระบบจึงดึงราคาจาก Trip.com เองไม่ได้ ถ้ามีไฟล์ข้อมูลจาก Trip.com ให้ใส่ `"source": "Trip.com"` ในแต่ละรายการ แล้วกรองตามแหล่งข้อมูลได้ · รูปแบบลิงก์แก้ได้ที่ `links.tripcom` ใน config)
- ตัวกรองอื่น: ย่าน, แหล่งข้อมูล, ค้นหาชื่อ, ราคาสูงสุด/ต่ำสุดต่อคืน, คะแนนรีวิว, จำนวนรีวิว, รวม/ไม่รวมที่ยังไม่มีรีวิว, ระยะห่างจากแนวถนน, ประเภทที่พัก, เฉพาะที่ใหม่/ลดราคา
- เรียงตาม ราคา, ความคุ้มค่า (คะแนน ÷ ราคา), คะแนนรีวิว, ระยะจากถนน หรือย่าน
- แผนที่แนวถนนพร้อมแนวระยะที่ยอมรับ กดจุดบนแผนที่เพื่อเลื่อนไปที่รายการนั้น
- ปุ่ม **ทำเครื่องหมายว่าเห็นแล้ว** บันทึกราคาไว้เป็นฐาน ครั้งต่อไปจะติดป้าย "ใหม่" หรือ "ลด X%" ให้เอง
- แจ้งเตือนในเบราว์เซอร์เมื่อดึงข้อมูลจาก URL รอบใหม่แล้วเจอที่ใหม่/ลดราคา และส่งออก CSV ได้
- ถ้ามี `config.json` หน้าเว็บจะใช้ย่านและเงื่อนไขเดียวกับระบบแจ้งเตือน ตัวกรองที่ตั้งไว้จะถูกจำในเบราว์เซอร์

## ตั้งค่าช่องทางแจ้งเตือน (environment variables)

| ช่องทาง | ตัวแปร |
|---|---|
| LINE (Messaging API) | `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_TO` (userId หรือ groupId) |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Discord | `DISCORD_WEBHOOK_URL` |

> LINE Notify ปิดบริการแล้วตั้งแต่ 31 มี.ค. 2025 จึงใช้ LINE Messaging API แทน
> (สร้าง Official Account → เปิด Messaging API → ออก Channel access token แล้วแอดบอทเป็นเพื่อน)

```bash
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
python3 hotel_alert.py snapshot.json --channels telegram
```

## ตั้งเวลาให้ตรวจอัตโนมัติ

ตัวอย่าง cron ตรวจทุก 3 ชั่วโมง (ให้สคริปต์ดึงข้อมูลของคุณเขียนไฟล์ snapshot ไว้ก่อน)

```cron
0 */3 * * * cd /path/to/hotel-alert && python3 hotel_alert.py /path/to/snapshot.json >> alert.log 2>&1
```

ข้อมูลตัวอย่างใน `sample_snapshot.json` มาจากการค้นหา Booking.com จริงเมื่อ 5 พ.ย. 2026
(เช็คอิน 6, 7 และ 14 พ.ย. 2026 คืนละ 1 คืน, ผู้ใหญ่ 2 คน, 1 ห้อง) ราคาอาจเปลี่ยนตลอดเวลา
