# Onsen for Two ♨️

เว็บหา Private Onsen & Spa แบบแช่ 2 คน ย่านพระราม 9 · ห้วยขวาง · รัชดา · รัชโยธิน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ฟีเจอร์
- กรองตามย่าน (เลือกได้หลายย่าน)
- กรองราคา (ต่ำสุด/สูงสุด, แถบเลื่อน, ปุ่มช่วงราคาสำเร็จรูป) ต่อ 2 คนต่อรอบ
- กรองวันว่างและช่วงเวลา (บ่าย / เย็น / ดึก) พร้อมแสดงรอบที่ว่างและเต็ม
- กรองเฉพาะร้านที่ยืนยันแล้วว่ามีห้องแช่คู่ส่วนตัว
- เรียงตามราคาหรือจำนวนรอบว่าง
- เพิ่มร้านเองได้ (บันทึกไว้ใน localStorage ของเบราว์เซอร์)

## ข้อจำกัดของข้อมูล
- ร้านจริง 3 ร้าน (Bayleaf, Avani Ratchada, TENSEI) อ้างอิงจาก GoWabi/WAUG — **ราคาเป็นค่าประมาณ ยังไม่ได้ยืนยันกับร้าน**
- **รอบว่างเป็นข้อมูลจำลอง** เพราะร้านไม่มี API เปิดให้ดึงข้อมูลจริง (ถ้าจะใช้ข้อมูลจริงให้แทนที่ฟังก์ชัน `slotsFor()` ใน `app.js`)
- ร้านที่ขึ้นต้นด้วย `[ตัวอย่าง]` เป็นร้านสมมติไว้สาธิต ปิดได้ด้วยตัวกรอง
- แก้ไขหรือเพิ่มข้อมูลร้านได้ที่ `data.js`
